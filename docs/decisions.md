# 결정 기록

단계마다 내린 결정이다. Claude는 선택지와 차이만 제시하고 추천하지 않는다. 고른 것과 이유는 직접 정한다. 결정에 이르기까지 오간 질의답은 [qa/](qa/)에 있다.

- 상태: **확정**은 고른 것이 있는 항목, **미정**은 아직 고르지 않은 항목이다.
- 이유가 "건너뜀"인 항목은 이유 없이 확정한 것이다("이유가 굳이 필요해? 건너 뛰어").
- 이유는 말한 그대로 옮긴다.
