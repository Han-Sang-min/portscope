# 진행 방식

진행 방식은 프로젝트 공통 [개발 표준](https://github.com/Han-Sang-min/dev-standard)을 따른다. 원칙, 결정 하나의 순서, 단계마다의 순서, 기록 규칙, 한계가 거기에 있다. 개발 표준은 비공개 저장소다.

## 이 프로젝트에만 해당하는 것

- 구성된 내용에 대한 질문에 모두 답할 수 있을 만큼 개념을 학습한다.
- 작업은 프로토콜 계층 순서로 나눈다.
- 단계 문서는 [steps/_template.md](steps/_template.md)를 복사해 쓴다.
- 추적표의 참고 자료에는 RFC 절 번호 등을 적는다.
